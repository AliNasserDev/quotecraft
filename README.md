# QuoteCraft

QuoteCraft is a polished, browser-based quote builder for freelancers and small service businesses.

## Features

- Live client-facing quote preview
- Itemized services with quantity and rate controls
- Discount, tax, deposit, and multi-currency calculations
- Business branding and optional payment links
- Draft, sent, and accepted statuses
- Local saved-quote history
- Copy-to-clipboard and print/PDF support
- Responsive desktop and mobile layouts

## Run locally

Open `index.html` directly in a modern browser, or serve the folder with any static web server.

Quote data is stored only in the browser via `localStorage`. No customer data is sent to a server.

## Deploy

This repository is configured as a static Vercel project with security headers in `vercel.json`.
